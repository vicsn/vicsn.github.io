Privacy Policy

Bundle Hunt for Vinted — Unofficial
Effective September 4, 2026

Bundle Hunt helps users find separate marketplace listings offered by the same seller. The extension operates locally in the user's browser and has no developer-operated server, analytics, advertising, or tracking.

Information handled

  • Search terms and selected categories entered in the extension are stored locally in Chrome so they can be restored later.
  • The current marketplace URL is checked when the user clicks the extension's toolbar button.
  • Public listing information returned by the marketplace—including item details, seller usernames, and seller IDs—is processed locally to produce search results and optional CSV exports.
  • Requests are sent directly from the user's browser to the Vinted website over HTTPS. The extension does not read, collect, export, or store passwords or authentication-cookie values.

How information is used

Information is used only to provide the extension's bundle-search, diagnostics, and CSV-export features. It is not sent to the developer, sold, used for advertising, or shared with data brokers. Vinted receives the search requests needed to return marketplace results and handles them under its own terms and privacy policy.

Storage and retention

Search preferences remain in Chrome's local extension storage until the user changes them, clears the extension's data, or uninstalls the extension. Search results remain in the open tab. CSV files are created locally and saved only when the user selects Export CSV.

Browser permissions

  • activeTab: permits access only to the tab on which the user invokes the extension.
  • scripting: inserts the extension's packaged interface and styles after the toolbar button is clicked. No remote code is executed.
  • storage: saves search terms and selected categories locally.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only to provide or improve the extension's single user-facing purpose.

Contact and policy changes

Privacy questions can be submitted through the developer contact or support link on the extension's Chrome Web Store listing. Material changes to this policy will be published at this URL with an updated effective date.
